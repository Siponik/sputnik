01ТВОИ ФАЙЛЫ
Папка с заметками .md
Одна заметка — один текстовый файл на компьютере. Это и есть база: её откроет и Obsidian, ничего не пропадёт.
02СПУТНИК ЧИТАЕТ
Находит связи сам
В тексте ищет [[ссылки]] на другие заметки, #теги и свойства из шапки. Из них строит карту базы.
03ТЫ РАБОТАЕШЬ
Вкладка «Знания»
Пишешь, ищешь, смотришь связи — в пяти видах ниже. Всё сохраняется в те же файлы сразу.

ЗНАНИЯ
Написать и читать
Слева папки → список заметок → в центре заметка → справа её связи и маленький граф.
ГРАФ
Увидеть всю базу
Точка — заметка, линия — ссылка. Крутишь колёсико ближе — точки становятся карточками с проводами.
ХОЛСТ
Собрать схему руками
Свободная доска: кладёшь заметки, картинки и текст, соединяешь сам. Для кампании DND или пайплайна.
КАРТОЧКИ
Референсы
Те же заметки папки, но крупно с картинками — удобно для подборок.
ТАБЛИЦА
Сравнить по полям
Каждая заметка — строка, поля из шапки — колонки: «где», «фракция», «статус». Можно править прямо в ячейке.
CTRL K · ЗАДАЧИ
Найти и связать
Поиск находит заметки вместе с задачами. В окне задачи — блок «Заметки», а пункты «- [ ]» превращаются в задачи.
ПРИВЕТКоротко: ты просто пишешь заметки и ставишь [[ссылки]]. Всё остальное — граф, связи, таблицы — Спутник строит сам из этих ссылок и полей. Файлы остаются твоими.
