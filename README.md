# 🛰 Спутник

Личная система с Claude. Первый модуль: каждое утро по будням бот присылает в Telegram сообщение «🛰 Спутник · утренняя сводка готова» с кнопкой «Открыть сводку».

Сама сводка собирается запланированной задачей Claude в 7:45 МСК и публикуется на постоянную страницу «Спутник · Утро». Этот репозиторий отвечает только за уведомление: GitHub Actions запускает `send.py` в 8:00 МСК.

## Файлы

- `send.py` отправляет сообщение через Telegram Bot API. Внешних зависимостей нет.
- `.github/workflows/morning-brief.yml` запускает его по будням в 05:00 UTC (8:00 МСК), можно запустить и вручную.

## Настройка

1. **Создайте бота.** Напишите @BotFather, команда `/newbot`, имя «Спутник», логин, например `siponik_sputnik_bot`. Сохраните токен.
2. **Узнайте свой chat id.** Напишите @userinfobot, он ответит числом `Id`.
3. **Нажмите Start у своего бота**, иначе он не сможет вам писать.
4. **Добавьте секреты** в репозитории: Settings → Secrets and variables → Actions → вкладка Secrets → New repository secret:
   - `TELEGRAM_BOT_TOKEN`: токен из шага 1
   - `TELEGRAM_CHAT_ID`: число из шага 2
5. **Добавьте переменную** там же, вкладка Variables → New repository variable:
   - `BRIEF_URL`: `https://claude.ai/artifact/Mftfm4G7jmnrQZhnVJw728`
6. **Проверьте.** Actions → «Утренняя сводка» → Run workflow. Через полминуты сообщение должно прийти в Telegram.

## Запуск локально

```bash
TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... BRIEF_URL=... python3 send.py
```

## Заметки

- GitHub может запускать задачи по расписанию с задержкой в несколько минут, особенно в начале часа.
- Если в репозитории 60 дней не было активности, GitHub приостанавливает расписание. Тогда достаточно зайти в Actions и включить его снова.
