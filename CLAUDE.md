## Решения (не пересматривать без пользователя)

- Источник правды — Google Tasks + Google Calendar. Своего сервера нет.
- Слой Спутника (статус на доске, тип задачи, теги, проект, этап ассета, приоритет, учёт времени, история привычек) — JSON, сейчас локально в `%APPDATA%\com.siponik.sputnik\layer.json`. План: синхронизация между компьютерами через Google Drive appDataFolder; запасной вариант — скрытый служебный список в Google Tasks (не тратит хранилище).
- Второй компьютер будет — синхронизация слоя важнее всего остального.
- Привычки хранятся в Google Tasks как задачи списка «Привычки», серии и история — в слое.
- Поля «Софт» и «Полигонаж» пользователю не нужны — не добавлять.
- ~~Google Drive переполнен~~ — 20.10 вечером пользователь освободил место, файл напоминаний `sputnik-reminders.json` на Drive снова работает. Ниже — прежнее решение (новые служебные данные всё равно лучше класть в Календарь/Tasks): **Google Drive основного аккаунта переполнен (20.10)** — подписка с местом у пользователя на другом аккаунте. Служебные данные Спутника (напоминания, статусы, слой для синхронизации) на Drive не класть: только Google Calendar (служебные события в «Спутник · входящие») или скрытый служебный список Google Tasks. `sputnik-reminders.json` пустой с 19.10 — напоминания не доходят, пока их не перенесут.
- Задачи со временем не дублировать событиями в Google Календаре (20.10): напоминаний через Telegram-бота достаточно.
- Стиль: дизайн-система «Спутник» (ссылка — в личных заметках). Тёмная тема основная, акцент clay `#D9774F`, золото `#E0A04A` для особого, «выполнено» сине-бирюзовое `#6FB6CF`. Токены и классы `sp-*` — в `tracker/src/styles/`. Знак — буква «С» из орбиты (компонент `Brand.svelte`).
- Макеты экранов: «Макеты экранов» (ссылка — в личных заметках) (Доска, Сегодня, Окно задачи, Привычки, Календарь — неделя и месяц).
- Календарь: неделя и месяц устроены одинаково — сверху одна панель (период, ‹ ›, «Сегодня», фильтры-переключатели «События / Задачи / Привычки / Дни рождения», переключатель «Неделя | Месяц»), справа одна панель выбранного дня. Без левой колонки. События Google — нейтральные плашки, задачи со временем — тонированы по типу и с кружком-отметкой, задачи на день и дни рождения — строка «весь день». Привычки: в неделе под шапками дней ряд точек (золотая — сделано, обводка clay — сегодня, пунктир — не по расписанию) со счётчиком «1/4»; клик по ячейке дня открывает в панели дня список привычек этого дня (на сегодня — с отметкой и серией), клик по подписи «привычки» раскрывает ряд в таблицу «привычка × день». В месяце — полоска внизу клетки. Привычки со временем (28.10) — ещё и блоки в сетке недели в своём интервале «с … до …» (без конца — полчаса; `habits.habitSpan`, `calendar.habitBlocks`): полупрозрачная пунктирная плашка цвета привычки, кружок — отметка (только сегодня), отмеченная — плотнее и сплошная рамка; неотмеченные занимают время для свободного окна и загрузки недели. Пересечение блоков в сетке считается по высоте на экране (`layoutBlocks`). Под сеткой недели — обзор: «Загрузка недели» (часы по дням), «Сроки и даты недели», карточка енота-космонавта, который предлагает самое свободное окно и одной кнопкой ставит туда задачу; на сетке это окно обведено золотым пунктиром. Сетка недели — сутки 0–24: часы, где за неделю что-то есть, 40 px, пустые сжаты до 12 px на час полосами с подписью «00–10», полоса не выше 36 px (`BAND_MAX`), клик по полосе раскрывает её часы до смены недели. Над сеткой «весь день» — до 3 строк на день (открытые выше выполненных) и «+ ещё N», раскрытая строка не выше трети экрана. Обзор под сеткой компактный и сворачивается в одну строку («Обзор недели ▾», `cal.over` в localStorage), в «Сроках» 3 строки. Плотная неделя для проверки — демо-список «Тест · нагрузка», снимки `calendar-week*.png`. Дни рождения — календарь «Дни рождения» (контакты Google), праздники — «Праздники России».
