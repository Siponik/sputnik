# Спутник — контекст для Claude

Личная система пользователя (Siponik, дизайнер 3D и игрового арта, Windows, Москва). Общаемся по-русски, на «ты» в текстах интерфейса, коротко. Пользователь не программист: объясняй простыми словами, команды давай готовыми к вставке в PowerShell. Не жди в запросах впустую: если нужно ждать (сборку, действие пользователя) — остановись и скажи, что проверить, пользователь сам вернётся.

## Что уже работает

Источники: Gmail, Google Calendar, Drive, веб. Кнопки «Выполнено / Рассмотрено» у пунктов, отметки в базе страницы (коллекция `marks`).
- **Telegram-бот** — `send.py` + `.github/workflows/morning-brief.yml`, по будням 05:00 UTC шлёт ссылку на сводку. Сейчас ссылку шлёт Google Apps Script (`reminders/Code.gs`, `morningTick_`); с 21.10 к ссылке добавляются задачи дня — `todayBrief_` в `BotTasks.gs`). Время, дни и пауза меняются командами боту `/time 7:30`, `/days будни|все`, `/off`, `/on`, `/now` (`reminders/Bot.gs`, опрос getUpdates раз в минуту, свойства скрипта `BRIEF_AT`/`BRIEF_DAYS`/`BRIEF_OFF`). Задачи через бота (20.10, `reminders/BotTasks.gs`): просто текст — новая задача (дата/время словами, `@список`, `#тип`, `!!!`, вторая строка — заметка; тип/приоритет/время — через `pendingLayer` статуса «Входящих», трекер забирает, включая `slot`), `/today`, `/week` (21.10: по дням на 7 дней вперёд), `/tasks [список]`, `/done N|текст`, `/move N|текст когда` (21.10: перенос срока, «без срока», время — в `pendingLayer.slot`), `/lists [список]` (основной список — свойство `TASKS_LIST`), `/review` (21.10: итог недели — сделано по спискам, просрочено, что дальше; сам приходит по пятницам в 18:00 МСК, `reviewTick_`, свойства `REVIEW_SENT`/`REVIEW_OFF`), кнопки ✓/Отменить/Вернуть (callback_query). Ответы мгновенные (20.10): вебхук на веб-приложение Apps Script (`doPost` в `Bot.gs`, развёртывание «telegram» ставит `apps-script.yml`), при сбое скрипт сам возвращается к опросу раз в минуту (`hookAlive_`, свойство `BOT_HOOK`). При смене меню команд — поднять `BOT_VERSION` в `Bot.gs`. Проект Apps Script «SputnikNotification» обновляется сам: `.github/workflows/apps-script.yml` после слияния в main делает `clasp push --force` из `reminders/` (секрет `CLASPRC_JSON`, настройка — `reminders/README.md`). Руками код в script.google.com не вставлять. Секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, переменная `BRIEF_URL` уже заданы в репозитории.
- **Трекер** — `tracker/`, Tauri 2 + Svelte 5 (runes, JS без TS). Установщик собирает `.github/workflows/tracker-build.yml` (windows-latest → релиз `tracker-0.6.N` с .msi в этом репозитории; версия приложения 0.6.<номер сборки> (с 21.10 вечером; раньше 0.5.N и 0.3.N) ставится `tools/ci/tracker-release.mjs`). При падении сборки лог уходит комментарием в issue «CI: сборка трекера».
- **Обновление из приложения** (с 19.10.2026): `tauri-plugin-updater`, `lib/updater.js`; проверка через 30 с после запуска и раз в 6 ч; с 0.6 — чип «✦ Версия …» в шапке с «Что нового» и «Обновить сейчас / Вечером / Пропустить», ручная проверка и «Ставить ночью» — Настройки → Обновления. Репозиторий публичный (с 19.10.2026), поэтому релиз сборки в нём же несёт подписанный .msi, .msi.sig и `latest.json` и помечается «последним»; приложение смотрит `…/Siponik/sputnik/releases/latest/download/latest.json`. Нужен один секрет Actions: `TAURI_SIGNING_PRIVATE_KEY` (содержимое `%USERPROFILE%.taurisputnik-updater.key`, пароль пустой; открытый ключ — в `tauri.conf.json`). Без секрета релиз выходит пререлизом без файлов обновления. Репозиторий публичный — никаких ключей, токенов и личных данных в коммиты (история проверена 19.10: чисто). Ключ потерять нельзя: без него установленные копии не примут обновление — только переустановка вручную.
- **Тестовые данные** — `tools/test-data/seed.mjs` создаёт списки «Тест · …» в Google Tasks, календарь «Спутник · тест» и папку на Drive; `--clean` удаляет. Первый запуск создал задачи и календарь, на Drive упал из-за переполненного хранилища (место уже освободили) — перед повтором нужен `--clean`.

## Решения (не пересматривать без пользователя)

- Источник правды — Google Tasks + Google Calendar. Своего сервера нет.
- Слой Спутника (статус на доске, тип задачи, теги, проект, этап ассета, приоритет, учёт времени, история привычек) — JSON, сейчас локально в `%APPDATA%\com.siponik.sputnik\layer.json`. План: синхронизация между компьютерами через Google Drive appDataFolder; запасной вариант — скрытый служебный список в Google Tasks (не тратит хранилище).
- Второй компьютер будет — синхронизация слоя важнее всего остального.
- Привычки хранятся в Google Tasks как задачи списка «Привычки», серии и история — в слое.
- Поля «Софт» и «Полигонаж» пользователю не нужны — не добавлять.
- ~~Google Drive переполнен~~ — 20.10 вечером пользователь освободил место, файл напоминаний `sputnik-reminders.json` на Drive снова работает. Ниже — прежнее решение (новые служебные данные всё равно лучше класть в Календарь/Tasks): **Google Drive основного аккаунта переполнен (20.10)** — подписка с местом у пользователя на другом аккаунте. Служебные данные Спутника (напоминания, статусы, слой для синхронизации) на Drive не класть: только Google Calendar (служебные события в «Спутник · входящие») или скрытый служебный список Google Tasks. `sputnik-reminders.json` пустой с 19.10 — напоминания не доходят, пока их не перенесут.
- Задачи со временем не дублировать событиями в Google Календаре (20.10): напоминаний через Telegram-бота достаточно.
- Стиль: дизайн-система «Спутник» (claude.ai/artifact/5UB1CRJ24ttREtMhP6B2o4). Тёмная тема основная, акцент clay `#D9774F`, золото `#E0A04A` для особого, «выполнено» сине-бирюзовое `#6FB6CF`. Токены и классы `sp-*` — в `tracker/src/styles/`. Знак — буква «С» из орбиты (компонент `Brand.svelte`).
- Макеты экранов: claude.ai/artifact/ABerF89JnVCYaWLB48sGDr (Доска, Сегодня, Окно задачи, Привычки, Календарь — неделя и месяц).
- Календарь: неделя и месяц устроены одинаково — сверху одна панель (период, ‹ ›, «Сегодня», фильтры-переключатели «События / Задачи / Привычки / Дни рождения», переключатель «Неделя | Месяц»), справа одна панель выбранного дня. Без левой колонки. События Google — нейтральные плашки, задачи со временем — тонированы по типу и с кружком-отметкой, задачи на день и дни рождения — строка «весь день». Привычки: в неделе под шапками дней ряд точек (золотая — сделано, обводка clay — сегодня, пунктир — не по расписанию) со счётчиком «1/4»; клик по ячейке дня открывает в панели дня список привычек этого дня (на сегодня — с отметкой и серией), клик по подписи «привычки» раскрывает ряд в таблицу «привычка × день». В месяце — полоска внизу клетки. Под сеткой недели — обзор: «Загрузка недели» (часы по дням), «Сроки и даты недели», карточка енота-космонавта, который предлагает самое свободное окно и одной кнопкой ставит туда задачу; на сетке это окно обведено золотым пунктиром. Сетка недели — сутки 0–24: часы, где за неделю что-то есть, 40 px, пустые сжаты до 12 px на час полосами с подписью «00–10», полоса не выше 36 px (`BAND_MAX`), клик по полосе раскрывает её часы до смены недели. Над сеткой «весь день» — до 3 строк на день (открытые выше выполненных) и «+ ещё N», раскрытая строка не выше трети экрана. Обзор под сеткой компактный и сворачивается в одну строку («Обзор недели ▾», `cal.over` в localStorage), в «Сроках» 3 строки. Плотная неделя для проверки — демо-список «Тест · нагрузка», снимки `calendar-week*.png`. Дни рождения — календарь «Дни рождения» (контакты Google), праздники — «Праздники России».
- Персонаж — енот-космонавт, **выбран 19.10: «белый винил»** — виниловая игрушка в белом скафандре с оранжевой нашивкой «С», тёмные перчатки и сапожки, **глаза-пуговки** (от плюшевого варианта), голова свободно помещается в шлем. Генератор — `design/mascot/coon.py` (актуальна секция «v3» в конце файла, координаты 240×260), готовые SVG `coon-<поза>.svg`, лист `poses.png`. Позы: hi (Сегодня, первый запуск), cheer (всё сделано, веха серии 7/21/50/100, пустые «Входящие»), flag (Привычки, запланированное окно), think (свободное окно, совет на доске), sleep (пустая колонка, свободный день, серия на паузе), oops (нет связи с Google), face (значок для уведомлений и бота). Анимации мягкие, при «уменьшении движения» замирают. Пустые колонки доски — маленький плоский **скетч-енот** (`design/mascot/peek/`, утверждён 20.10): выглядывает снизу, подглядывает сбоку или свешивает хвост; правила — `docs/design-v2.md`, «Пустые колонки». В трекере — `lib/PeekCoon.svelte` (`peekVariant(ключ колонки, номер)`: место чередуется по колонкам, край и сдвиг — по ключу: выглядывает снизу или сверху головой вниз, сбоку слева или справа, хвост у левого или правого края), стили — `styles/board.css`, анимации — `design/mascot/peek/peek.css` (подключён в `app.css`). ## Устройство трекера

- `tracker/src-tauri/src/google.rs` — вход в Google (OAuth для установленных приложений, PKCE, loopback 127.0.0.1), токен в `token.json` в папке настроек, команда `gapi(method, url, body)` (только `*.googleapis.com`), автообновление токена.
- `tracker/src-tauri/src/lib.rs` — команды `layer_read` / `layer_write`. Резервные копии слоя (`src/backup.rs`): раз в день перед первой записью — `backups/layer-ГГГГ-ММ-ДД.json` в папке настроек, хранятся 14; испорченный `layer.json` откладывается как `layer.broken.json`, слой читается из свежей целой копии. Проверка модуля без Tauri: `rustc --edition 2021 --test src/backup.rs`.
- Ключ Google Cloud (проект `sputnik-512107`, клиент Desktop app): пользователь выбирает `client_secret.json` при первом запуске, приложение копирует его в папку настроек. Файл лежит в `D:\Project\sputnik\client_secret.json` и исключён `.gitignore` — никогда не коммитить и не выводить содержимое.
- Фронтенд: `src/App.svelte` (состояние, синхронизация раз в 2 мин), `lib/Board.svelte` (канбан inbox/doing/review/done, перетаскивание), `lib/Today.svelte`, `lib/TaskDrawer.svelte`, `lib/Setup.svelte`, `lib/api.js`.
- В окне Tauri `dragDropEnabled: false`, иначе HTML-перетаскивание не работает на Windows.
- Календарь (19.10.2026, этап 1 переделки интерфейса): `lib/Calendar.svelte` (панель, фильтры, панель дня, обзор недели, енот), `lib/CalWeek.svelte`, `lib/CalMonth.svelte`, расчёты — `lib/calendar.js`, события за период — `api.eventsRange` (дни рождения по `#contacts@` или `eventType: birthday`, праздники — `ru.russian#holiday@…`, добавляется сам; очередь «Спутник · входящие» скрыта). Время задачи — в слое `tasks[id].slot = { s, e }` («ЧЧ:ММ»), поле «Время» в окне задачи. Тип задачи для цвета пока = шаблон списка (work/asset3d→creative/personal/study). Енот — `lib/Coon.svelte`: SVG импортируются прямо из `design/mascot/` (в `vite.config.js` `fs.allow: ['..']`), стиль из SVG вынесен в `styles/coon.css`, id градиентов переименовываются на каждый экземпляр. Задачи в неделе перетаскиваются (21.10, `CalWeek` → `onmove` → `Calendar.moveItem` → `schedule`): в сетку — новый день и время с шагом 15 мин, длительность прежняя (без времени — час), в строку «весь день» — день без времени; в месяце (`CalMonth`) — на другой день, время сохраняется; выполненные не тащатся.
- Общая шапка (с 0.6 — см. «Версия 0.6» ниже): «Сегодня · Календарь · Доска · Привычки», «Входящие от Claude · N», кнопка «Создать» и Ctrl+N (окно «Создать» v2 — `lib/Create.svelte`, с 21.10 вместо `QuickAdd.svelte`; экран может перехватить через `quickLine`).

Снимки в демо: `create-личное/работа/3D/куда/событие/др.png`.

- Выполненные больше 3 дней назад уходят с доски в «Архив» (поиск, все списки, «Вернуть»).
- Шаблоны списков (`lib/templates.js`): Работа, 3D-ассеты (колонки = этапы пайплайна), Личное, Учёба. Шаблон хранится в слое `lists[listId].template`, выбирается только при создании списка (с 20.10 в шапке доски его сменить нельзя).
- Экран «Привычки» (`lib/Habits.svelte`, `lib/habits.js`): привычки — задачи списка «Привычки» (он скрыт с доски и из «Сегодня»), расписание в `habits[id]`, отметки в `log["id|YYYY-MM-DD"]`.
- Напоминания (`lib/reminders.js`): в Google Tasks их нет, правило в слое `tasks[id].remind` (за N дней до срока в ЧЧ:ММ или точное время). Трекер пишет `sputnik-reminders.json` в папку «Спутник» на Drive, а Google Apps Script (`reminders/Code.gs`, настройка в `reminders/README.md`) раз в минуту шлёт их боту. GitHub Actions не подошёл: в приватном репозитории частый cron не влезает в бесплатные минуты.
- В записях слоя есть поле `t` (время изменения) — под слияние из `wip/layer-sync`.

Шаг 2 сделан 21.10 (ветка `claude/night-layer-sync`): `tracker/src/lib/layer.js` — слияние слоя по записям (побеждает больший `t`, при равном — одинаковый выбор на всех компьютерах), файл `sputnik-layer.json` в appDataFolder Drive; право `drive.appdata` в `google.rs` (кто входил раньше — «Войти заново» в Настройки → Синхронизация). `syncLayer()` в App: после каждой синхронизации с Google и через 4 с после `saveLayer()`. Удаление записи — «надгробие» `{ gone: true, t }`, не `delete`. Новый раздел слоя — добавить в `SECTIONS` в `layer.js` (неизвестные разделы с другого компьютера и так не теряются). Ветка `wip/layer-sync` устарела.
