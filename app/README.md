# Flutter-версия Спутника — только образец

Не собирается и не проверяется: Спутник переписан на Rust + Slint (`rust/`). Шрифты и еноты переехали в `rust/assets/`,
золотые файлы тестов — в `rust/core/tests/golden/`. Папка лежит как образец для переноса оставшихся экранов «Знаний»
(холст, карточки, таблица, поиск) и будет удалена, когда они готовы в Rust-версии.
