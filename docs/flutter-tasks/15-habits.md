# Задача 15: перенести `habits` в Dart

**Прочитай сначала:** `docs/flutter-architecture.md` (особенно п. 4 «Как переносится логика» и «Подводные камни JS → Dart»).

- Источник: `tracker/src/lib/habits.js` (~498 строк), старый тест: `tracker/tests/habits.test.js`
- Куда: `app/lib/core/habits.dart`, тест `app/test/core/habits_test.dart`
- Нужно готовое до этой задачи: нет
- Важно: Самый большой модуль (~500 строк). Переноси только чистые функции; то, что зовёт api.js, пропусти и перечисли в PR. Можно двумя PR: серии/вехи и остальное.

## Шаги
1. Создай `tools/golden/habits.mjs` по образцу `tools/golden/gen.mjs` (тот же `write`, одна строка — один случай):
   импортируй функции из `../../tracker/src/lib/habits.js`, прогони их на входах и запиши `app/test/golden/habits.json`.
   Входы: все примеры из старого теста + граничные (пустые значения, конец месяца/года, русский регистр, дубликаты).
   Если функция зависит от «сейчас» — передавай дату явно. Запуск: `node tools/golden/habits.mjs`.
2. Перенеси в `app/lib/core/habits.dart` все экспортируемые чистые функции: те же имена, те же правила.
   Шапка файла: `// Порт tracker/src/lib/habits.js`. Не импортируй `data/`, `state/`, `ui/` и Flutter — только Dart и `core/`.
3. Тест читает golden-файл и для каждого случая требует тот же ответ (образец — `app/test/core/when_test.dart`).
4. `cd app; dart format -l 120 lib test; flutter analyze; flutter test` — без ошибок.

## Нельзя
- менять `tracker/`, `bot/`, `reminders/` и чужие файлы в `app/`;
- добавлять пакеты;
- «чинить» поведение старого кода: если JS делает странно — повтори и опиши в PR.
