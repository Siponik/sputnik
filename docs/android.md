# Спутник для Android — экраны и план (21.10.2026)

Экраны утверждены пользователем как направление (21.10). Макеты — `design/screens/Mobile{Daily,Boards,More}.dc.html`
(холст, страница «Android»), картинки — `design/screens/ref/mobile-*.png`. Это **тот же трекер** (`tracker/`), собранный
Tauri 2 под Android, а не отдельное приложение: экраны, `lib/*.js`, слой, напоминания — общие.

## Порядок работ

0. **Не начинать, пока** десктоп 0.3 не проверен на реальном аккаунте и синхронизация слоя (`lib/layer.js`) не проверена
   между двумя компьютерами — телефон станет третьим устройством того же слоя.
1. **Проба (spike), отдельная ветка `claude/android-spike`.** Цель — ответить «да/нет» на два вопроса, без нового дизайна:
   - собирается ли текущий трекер под Android (`npm run tauri android init`, `npm run tauri android dev` на эмуляторе);
   - работает ли **вход в Google** и чтение задач/календаря на телефоне.
   Итог пробы — короткий отчёт в `docs/android.md` (раздел «Итоги пробы») и APK, который пользователь ставит на телефон.
2. Мобильная раскладка по макетам (ниже), по экрану за коммит: оболочка и навигация → Сегодня → Добавление →
   Привычки → Календарь → Доска (Стикеры, Канбан, Конвейер) → Окно задачи → Первый запуск.
3. Сборка APK в GitHub Actions (`.github/workflows/android-build.yml`, `ubuntu-latest`): релиз `android-0.1.N` с подписанным
   `.apk` в этом репозитории. Ключ подписи — секрет Actions (`ANDROID_KEYSTORE_B64`, `ANDROID_KEY_PASSWORD`), **никогда не
   в коммит**. Пользователь ставит APK вручную; Google Play — позже и только по решению пользователя.

## Вход в Google на Android (главный риск)

Десктопный способ (loopback `127.0.0.1`, `google.rs`) на Android не подходит, а свои схемы адресов (custom URI scheme)
Google для новых Android-клиентов отключил. Предполагаемый путь:
- В Google Cloud (проект `sputnik-512107`) создать клиент OAuth типа **Android**: имя пакета приложения + SHA-1 ключа
  подписи (отладочного и релизного — два отпечатка). Это делает пользователь по инструкции; ключей в репозиторий не класть.
- В приложении — небольшой плагин Tauri на Kotlin, который через Google Identity Services (`AuthorizationClient`,
  `Identity.getAuthorizationClient(activity).authorize(...)`) просит те же права: Tasks, Calendar, `drive.appdata`,
  и отдаёт **access token** в JS. Refresh-токена нет: когда токен истёк — тот же вызов ещё раз (обычно без окна).
- `gapi()` на Android ходит в `*.googleapis.com` с этим токеном (тот же список разрешённых адресов, что в `google.rs`).
- Если этот путь не сработает — описать, что именно отказало, и остановиться: решать с пользователем.

## Что отличается от компьютера

- Нет: своей полосы окна (`WinControls`), самообновления (`tauri-plugin-updater` — только десктоп), горячих клавиш и окна «?».
- Уведомления: `tauri-plugin-notification` работает и на Android, но **основной канал напоминаний остаётся бот** (решение 20.10).
- Перетаскивание заменено долгим нажатием и листом «Перенести в…». Свайпы по строкам задач.
- Определение «телефона» — ширина окна < 600 px (`lib/device.js`, `isPhone`), а не платформа: так мобильную раскладку можно
  проверять в `npm run demo` с узким окном (`npm run shot` — добавить снимки 392×852 рядом с `ref/mobile-*.png`).

## Экраны (по макетам)

Общее: телефон 392×852, нижняя навигация «Сегодня · Календарь · Доска · Привычки» (активная — значок clay на подложке
`--clay-soft`), круглая-квадратная кнопка «+» 58 px справа снизу (clay) — быстрое добавление. Листы снизу (`sheet`)
с «ручкой», затемнение фона 50 %. Цвета и шрифты — те же токены, тёмная и светлая темы. Касательные цели ≥ 44 px.

- **Сегодня** (`MobileDaily`, 1-й): дата + «Сегодня» шрифтом `--font-display`, енот `hi`. Карточка clay-soft с кольцом
  «2 из 6 сделано» и «Дальше — … через N мин». «Привычки 1/4» — ряд кругов 54 px с эмодзи, касание = отметка (золото),
  «Все» → экран привычек. «Задачи» — строки 58 px: кружок 26 px (обводка цветом приоритета), название, ниже точка списка,
  список, срок/подзадачи; справа время. **Свайп вправо** — сделано (бирюзовая подложка «✓ Сделано»), **влево** — перенести
  (золотая подложка, лист «Сегодня вечером / Завтра / На выходных / Выбрать…»). Касание — окно задачи. Внизу «Входящие от Claude · N» с «Принять все».
- **Быстрое добавление** (`MobileDaily`, 2-й): лист снизу поверх экрана, сразу с клавиатурой. «Задача | Событие | День рождения».
  Поле ввода: распознанные куски (`parseWhen`, `#тема/#тип`, `!!!`) подсвечены clay и тут же показаны чипами (срок, тема,
  напоминание, повтор, приоритет); касание чипа — поправить. Слева снизу — список (`Дела по дому ▾`), справа «Добавить».
- **Привычки** (`MobileDaily`, 3-й): «Октябрь · 14 из 19 дней». Веха — плашка с енотом `cheer`. Карточка привычки: значок,
  название, расписание, 🔥 серия, круглая кнопка отметки 46 px (золото), ниже неделя кружками (сделано — золото, сегодня —
  обводка clay, не по расписанию — пунктир). Касание карточки — месяц целиком (`habits.monthGrid`).
- **Календарь · день** (`MobileBoards`, 1-й): «День | Месяц». Лента недели (касание — день, свайп — неделя, точки — число дел).
  Строка «весь день» (дни рождения). Сутки как на компьютере: занятые часы 46 px, пустые сжаты в полосы «00–09».
  События — нейтральные плашки, задачи — тонированы по типу с кружком, линия «сейчас» clay. Свободное окно — золотой пунктир
  с енотом `think` и предложением поставить задачу (касание — поставить).
- **Календарь · месяц** (`MobileMore`, 3-й): сетка 7×N, в клетке до 3 цветных полосок дел, золотая полоска внизу — привычки дня
  сделаны. Сегодня — заливка clay. Касание — список дня под сеткой; второе касание — «День».
- **Доска · Стикеры** (`MobileBoards`, 2-й): выбор списка в заголовке (`Дела по дому ▾` — лист со списками по сферам).
  «По темам | По срокам». Разделы идут вниз, стикеры в две колонки, всё как в `docs/design-v2.md` «Стикеры». Баночка — слева снизу.
- **Доска · Канбан** (`MobileBoards`, 3-й): одна колонка на экран, вкладки колонок сверху (подчёркивание цветом колонки,
  лимит «2/3»), точки-страницы; свайп влево/вправо — соседняя колонка. **Долгое нажатие** на карточку: она приподнимается,
  снизу лист «Перенести «…»» — колонки (текущая отмечена) и три кнопки «Срок / Приоритет / Другой список».
- **Доска · Конвейер** (`MobileMore`, 2-й): сводка «4 ассета · 1 просрочен…», группы по проекту, карточка ассета:
  миниатюра, название, срок, дорожка этапов (пройденные бирюзовые, текущий clay) и «Ретопология · 3 дня». Касание раскрывает
  чек-лист этапа и кнопки «Открыть» / «UV →»; открыта одна карточка за раз.
- **Окно задачи** (`MobileMore`, 1-й): лист снизу почти на весь экран (тянется до верха). Путь «список · колонка», название,
  дорожка этапов, поля Срок / Приоритет / Напомнить / Повтор / Время (таймер), подзадачи, заметка. Нижняя панель:
  «⋯ Ещё», «Срок», главное действие — следующий этап (у стикера — «Сделано»).
- **Первый запуск** (`MobileMore`, 4-й): енот `hi`, «Привет! Это Спутник», три доступа с объяснением, «Войти через Google»,
  подсказка «доски, темы и привычки подтянутся с компьютера».
