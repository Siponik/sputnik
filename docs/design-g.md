Утверждён пользователем 05.11: «все чётко, мне нравится». **Меняется только вид** — что где лежит, клавиши и поведение остаются как в `docs/design-v2.md` и CLAUDE.md. Код трекера под систему G ещё не переделан; переносить по шагам, каждый — PR в `beta`.

Где лежит:

- Копии экранов — `design/system-g/screens/*.dc.html` (открываются в браузере как обычный HTML; `canvas.json` — раскладка холста).

## Идея

Экран — схема из **нод**, соединённых **проводами**, как в нодовом редакторе, плюс строгость чертежа: нумерация `01 · …`, тонкие линии, размерные линии с засечками, штамп листа в углу. Главная нода экрана (например «Сегодня» в середине) крупнее, с уголками-скобками по углам. Источники слева (списки, привычки, «От Claude»), вывод справа («Дальше», «Итог дня», енот).

Светлая тема — экран «Сегодня · светлая тема» (`G_TodayLight`), получен заменой токенов (`LIGHT` в `gen/s_b5.py`); остальные экраны — по той же таблице, цвета для светлой при переносе подогнать по контрасту.

## Шрифты и формы

- Onest — текст (200 для больших цифр, 400/500/600), JetBrains Mono — служебное: шапки нод ЗАГЛАВНЫМИ с разрядкой, время, счётчики, штамп.
- Скругления (решение: без острых квадратов): нода 8, главная нода 12, кнопки 6, сокеты 3, привычки — таблетки.
- Сокет — квадрат 10px на краю ноды, по центру своей строки; провод — кривая Безье цвета сферы, ждущие — пунктир.

## Тон окон (решение 05.11 по «Создать»)

Окна, где пользователь что-то вводит («Создать», окно привычки, настройки, окно задачи), — дружелюбные: подписи обычными словами с заглавной («Что нужно сделать?», «Куда положить», «Напомнить»), чипы-варианты вместо моно-капса, без проводов внутри окна. Моно-капс остаётся в шапках нод и на служебных метках. В «Создать» шапка окна — сегмент «Задача / Событие / Привычка / День рождения» на заливке цвета вида: задача — оранжевый, событие — синий, привычка — золотой, день рождения — фиолетовый.

## Как переносить в трекер

1. Токены — в `tracker/src/styles/tokens.css` (новые имена рядом со старыми, потом заменить), шрифты Onest и JetBrains Mono — в сборку, без загрузки из сети.
2. Общие детали: шапка, нода с цветной шапкой, кнопки, чипы, точки холста.
3. Экраны по одному в порядке: Сегодня → Доска → Календарь → Привычки → окна → настройки. Провода между нодами — только там, где они есть на макете.
