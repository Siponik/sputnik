# Спутник 0.6.0 — что входит и в каком порядке (21.10.2026)

Холст: страница **«Версия 0.6.0»** — все экраны версии в одном месте (claude.ai/artifact/ABerF89JnVCYaWLB48sGDr).
Ряды: 1 — Сегодня, Календарь (неделя, месяц), Привычки; 2 — доска (колонка, Канбан, Конвейер, Стикеры по темам/срокам);
3 — колонка откреплена / выехала, «Состояние», новая версия, нет связи; 4 — «Создать» (3 вида + куда/событие/ДР), Настройки;
5 — Сферы, Шаблоны, Дата и время, Первый запуск, Енот. Спецификации — `docs/design-v2.md` (разделы ниже), эталоны —
`design/screens/ref/`. Работать как в `docs/kanban-handoff.md`: демо → `npm run shot` → сравнение → маленькие коммиты →
`npm test` и `npm run build` после каждого.

## Новое в 0.6 — по порядку
1. **Номер версии**: `tools/ci/tracker-release.mjs` — `0.6.${run}`; `tauri.conf.json` и `package.json` — `0.6.0`; в CLAUDE.md «tracker-0.6.N».
2. **Шапка** на всех экранах (раздел «Шапка, левая колонка доски, «Состояние», обновления и настройки», часть «Шапка»):
   вкладки с «таблетками»-счётчиками, «Найти · Ctrl K», кнопка «Состояние» (3 точки), Входящие с бейджем, ⚙, «Создать»
   (одна кнопка на всех экранах; на «Привычках» открывает новую привычку, как раньше «Новая привычка»). Кнопка «?» уходит.
   Эталон шапки — верх любой доски страницы 0.6 (`ref/shell-обычный.png`).
3. **«Состояние»** — поповер (Google / между компьютерами / версия / напоминания), точки и подписи; полоса «Нет связи»
   в одну строку (`ref/shell-нет связи.png`, `ref/shell-состояние.png`).
4. **Обновления**: чип «✦ Версия …» в шапке вместо полосы, поповер «что нового» с «Обновить сейчас / Вечером / Пропустить»,
   прогресс в чипе (`ref/shell-обновление.png`).
5. **Левая колонка доски**: три части (прокрутка / совет енота прибит к низу / док «Шаблоны · Архив · Показывать»),
   фильтр «Список…», значки вида у списков, совет с действием; **закрепить / открепить** булавкой и `Ctrl+B`,
   откреплённая — полоса 64 px и **выезд поверх доски при наведении** (150 мс / уход 300 мс)
   (`ref/shell-обычный.png`, `ref/shell-свёрнуто.png`, `ref/shell-наведение.png`). Сферы и Шаблоны — та же колонка.
6. **Настройки** — окно с вкладками Вид / Что показывать / Напоминания / Синхронизация / Обновления / Клавиши, поиск,
   `Ctrl+,` (`ref/settings-*.png`). Сюда переезжает всё из старого низа колонки.
7. **«Сегодня» 0.6** (раздел «Сегодня» в 0.6): умная строка с «Понял» и «Куда», метка-список, круглые отметки,
   привычки «таблетками», компактные Входящие (`ref/today-0.6.png`).
