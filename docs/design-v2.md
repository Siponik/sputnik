# Спутник · дизайн v2 — что реализовать в трекере

Утверждено пользователем 19.10.2026. Макеты: холст «Макеты экранов» (ссылка — в личных заметках проекта), страница **«Новые экраны»**.
Исходники экранов (рабочие, с логикой) лежат в `design/screens/*.dc.html` — это формат холста Design (HTML + `{{дырки}}` +
класс `Component.renderVals()`), его не запускать как есть: брать вёрстку, стили и поведение и переносить в Svelte.
Енот — `design/mascot/` (генератор `coon.py`, готовые `coon-<поза>.svg`, лист `poses.png`).

## Если макет спорит с тем, что уже сделано в 0.2

Решения из трекера 0.2 главнее макета:
- **Карточки на доске без галочки** — выполнение только переносом в «Готово» или сменой статуса. В макете доски у карточек
  есть галочка — в приложение её НЕ переносить; стрелка «→ следующий этап» из макета как раз дополняет это решение.
- «Готово» → через 3 дня в «Архив» — остаётся; свёрнутая колонка «Готово» из макета работает поверх этого.
- Шаблоны списков, напоминания, «Входящие от Claude» через Apps Script — как есть.

## Общее

- Навигация (вкладки) во всех экранах одна: **Сегодня · Календарь · Доска · Привычки**, справа — статус синхронизации,
  «Входящие от Claude · N», основная кнопка «Создать / Новая задача». Горячая клавиша **Ctrl+N** — быстрое добавление.
- Стили: токены и классы `sp-*` уже есть в `tracker/src/styles/`. В макетах токены продублированы в `<helmet><style>`
  (`.sp-app{--bg:…}`) — сверить и добавить недостающие: `--gold-soft`, `--clay-soft`, `--signal-done`, `--type-*`.
- Тёмная тема основная, светлая — `data-theme="light"`.
- Все анимации — только при `prefers-reduced-motion: no-preference`.

## Енот-космонавт (белый винил, глаза-пуговки)

Компонент `Coon.svelte`: `<Coon pose="hi" size={150} label="…"/>`.
- Взять разметку из `design/mascot/coon-<поза>.svg` (inline SVG, не `<img>` — нужны CSS-анимации и переменные).
  Или портировать генератор: секция «v3» в конце `coon.py` (`pose_svg`, `CSS`) — 240×260, сон 250×260, значок `30 0 180 186`.
- **id градиентов уникальны на каждый экземпляр** (`cn-` → `cn<N>-`), иначе несколько енотов на экране ломают друг другу заливку.
- Позы и где: `hi` — Сегодня, первый запуск; `cheer` — всё сделано, веха серии, пустые «Входящие»; `flag` — Привычки,
  запланированное окно; `think` — совет на доске, поиск свободного окна; `sleep` — пустая колонка, свободный день, серия на паузе;
  `oops` — нет связи с Google; `face` — значок (уведомления, бот).
- Анимации: парит, моргает, мигает антенна, хвост покачивается, машет лапой (`hi`), прыгает (`cheer`), «z» (`sleep`).

## Экраны

### Сегодня (`Today.dc.html`)
- Шапка: дата, заголовок-итог дня, полоски «Задачи N из M» и «Привычки N из M», плашка **«Дальше: <событие> · через N мин»**
  (ближайшее событие/задача со временем), справа енот + реплика (`hi`, когда всё сделано — `cheer`).
- **Строка быстрого добавления** сверху списка: Enter — добавить в «Сегодня». Разбор: `17:00` / `17.00` → время,
  `#ассет #работа #клиент #учёба #личное` → тип. Новая задача помечена «новая». Подсказка под строкой: «можно и из чата Claude».
- Группы «Просрочено · N» (красным, в рамке) и «Сегодня · N».
- После отметки задачи — **плашка «Готово: «…» · Отменить»** внизу (~5 с), отмена возвращает задачу.
- Блок «Привычки» (отметка + серия), блок «Входящие от Claude» с «Принять / Отклонить» и **«Принять все»** (если больше одного).
- Справа: расписание дня по часам, линия «сейчас»; в конце дня свободное окно — дремлющий енот.

### Доска (`Main.dc.html`)
- Слева сферы и проекты, внизу карточка-совет с енотом `think` («Начни с …» — первая по сроку).
- Колонки Входящие / В работе / На ревью / Готово. Фильтр по типу сверху.
- **«+ Добавить задачу»** открывает форму прямо в колонке: поле, «Добавить» / «Отмена», Enter / Esc.
- **Стрелка на карточке** (видна при наведении и фокусе) — перенос на следующий этап; из «На ревью» → «Готово».
- **Лимит «В работе» = 3**: бейдж «N / 3», при превышении — мягкое предупреждение под заголовком.
- «Готово» свёрнуто до 2 карточек + «Ещё N →».
- Пустая колонка: **маленький скетч-енот** вместо большого 3D (см. раздел «Пустые колонки» ниже).

### Привычки (`Habits.dc.html`)
- Шапка: итог, «Сегодня отмечено / Серий идёт / Самая длинная», енот `flag` с репликой про ближайшую веху.
- **Ряд «Сегодня»** — пилюли всех привычек, отметка в одно касание (рядом серия).
- Карточка привычки: крупное число серии (золотое от 7), **шкала вех 7 · 21 · 50 · 100** (нелинейная, равные отрезки),
  «До вехи N: M дней · лучшая K», сетка 13 недель.
- **«Взять выходной»** — 1 раз в неделю на привычку, серия не сгорает; в сетке день выходного — бирюзовый пунктир.
  Хранить в слое (история привычек), правило «не чаще раза в 7 дней» проверять при отметке.
- Серия 0 — вместо числа дремлющий енот «Отметь сегодня — и енот проснётся».
- **Веха** (7/21/50/100) при отметке → плашка-праздник с енотом `cheer` и «Ура!»; плюс уведомление Windows и сообщение бота
  (бэклог из CLAUDE.md — можно через тот же список напоминаний).

### Календарь — неделя (`Calendar.dc.html`) и месяц (`CalendarMonth.dc.html`)
Схема из CLAUDE.md остаётся (одна панель инструментов, одна панель дня справа, фильтры, «Неделя | Месяц»). Новое:
- **Сутки 0–24 со сжатием**: час, где за неделю есть хоть одна запись (или текущий час, или открытый черновик), — 40 px;
  пустые часы — 12 px, подряд идущие сливаются в заштрихованную полосу с подписью «00–10». Позиции считаются через
  накопленные высоты (`Y[h]`) и `yAt(минуты)`; линии часов только между обычными часами.
- **Клик по пустому часу** (подсветка «+ 14:00» при наведении) — открывает форму в панели дня с этим временем,
  в сетке — пунктирный черновик clay.
- **Форма «＋ Добавить на этот день»** в панели дня (и неделя, и месяц): название, Задача / Событие, время
  (весь день / 10:00 / 14:00 / 19:00 / выбранное), подсказка куда попадёт: задача → Google Tasks (срок; со временем —
  ещё и в сетку, см. шаг 5 плана), событие → Google Календарь. Enter — создать, Esc — закрыть.
- Ряд точек привычек под днями недели + раскрытие в таблицу «привычка × день» (как было).
- Под сеткой недели обзор: «Загрузка недели» (часы занятости по дням), «Сроки и даты недели», карточка енота со
  **свободным окном** (самый длинный просвет рабочих часов) и кнопкой «Запланировать» — ставит туда задачу.
- Свободный день в панели — дремлющий енот.

### Первый запуск (`Setup.dc.html`)
- Шаги 1 Ключ Google → 2 Вход → 3 Что показывать (списки Tasks и календари галочками) → готово.
- Перед входом — **список доступов простыми словами** (Задачи, Календарь, Drive только свои файлы, своего сервера нет).
- Справа енот `hi` с репликой; после завершения — `cheer` и три подсказки: Ctrl+N, «запиши в Спутник» из чата, сводка 7:45.
- Нет связи с Google — енот `oops`, «Попробую снова через минуту», кнопка «Повторить сейчас».

## Порядок работ (предложение)
1. `Coon.svelte` + общая навигация и Ctrl+N.
2. Сегодня: быстрое добавление с разбором, «Дальше», «Отменить», «Принять все».
3. Доска: форма в колонке, стрелка этапа, лимит, свёрнутое «Готово», пустые колонки с енотом.
4. Привычки: ряд «Сегодня», вехи + праздник, «выходной» в слое.
5. Календарь: неделя 0–24 со сжатием, форма добавления, свободное окно; месяц — форма и пустой день.
6. Первый запуск: доступы, подсказки, состояние «нет связи».
После каждого пункта — сборка в CI и короткая инструкция пользователю, что проверить.

## Пустые колонки: скетч-енот (утверждено 20.10)

В пустой колонке доски (пунктирная рамка с текстом) вместо большого 3D-енота — маленький плоский **скетч-енот**:
неровная карандашная линия, маска штриховкой, один цвет. Файлы — `design/mascot/peek/`:
`peek-bottom.svg`, `peek-side.svg`, `tail.svg`, анимации `peek.css`, генератор `peek.py`, превью `preview.png`.

- Цвет — `currentColor` (как у вторичного текста, `--ink-faint`), фон-«дырки» — `var(--bg)` → сам подстраивается под тему.
- В файлах id `PKID-rough`, `PKID-hatch`, `PKID-c` — **на каждый экземпляр заменить `PKID` на уникальный** (иначе фильтр/штриховка
  одного енота ломает другого). Удобно: компонент `PeekCoon.svelte` с `place` = `bottom | side | tail`, вставляет SVG через `{@html}`
  с подставленным id.
- Три места в рамке (рамка `position: relative`):
  - `bottom` — выглядывает из-за нижнего края: по центру, `bottom: -2px`, масштаб ×1.25 (125×63). Текст прижат вверх:
    отступ снизу ≥ 92 px, чтобы уши не задевали текст. Время от времени прячется и выглядывает.
  - `side` — подглядывает из-за правого края: `right: -2px`, по вертикали по центру, `transform: scaleX(-1)`, ×1.3. Текст с отступом справа ~92 px.
    Без лапки.
  - `tail` — свисает пушистый полосатый хвост из-под верхнего края: `left: ~44px; top: -2px`, ×1.3. Текст с отступом слева ~104 px. Покачивается.
- Чередовать места по колонкам (например, по индексу колонки), чтобы не было одинаково везде. Тексты: «Ничего в работе. Возьми задачу
  из входящих.», «На ревью пусто. Енот ждёт новую работу.», «Входящие разобраны. Можно выдохнуть.»
- Анимации только при `prefers-reduced-motion: no-preference` (в `peek.css` уже есть).
- Большой 3D-енот остаётся для остальных мест (Сегодня, Привычки, Календарь, Первый запуск).

## Выбор даты и времени в задаче (утверждено 20.10)

Исходник — `design/screens/DateTime.dc.html` (холст: «Окно задачи · дата и время»). Компонент `DateTimePicker.svelte`,
открывается по клику на поле «Срок» в окне задачи (и везде, где выбирается дата: форма в календаре, быстрое добавление).
Всплывающее окно ~640 px, не закрывает само окно задачи (встаёт слева от него), Esc / клик снаружи — закрыть.

1. **Строка «словами»** сверху: «сегодня/завтра/послезавтра», дни недели («в пятницу» → ближайшая будущая), «через N дней/недель»,
   «25 окт», время «15:00 / 15.00». Справа живой итог: «пт, 23 окт · 17:30–18:30». Enter — применить и закрыть.
   Разбор — отдельная функция `parseWhen(text, today)` в `lib/`, её же использует строка быстрого добавления на «Сегодня».
2. **Быстрые кнопки** с подписанной датой: Сегодня · Завтра · Пятница · Пн · Через неделю (выбранная подсвечена).
3. **Календарь месяца** (пн–вс, ‹ ›): сегодня — обводка clay, выбранный — заливка clay, прошедшие и чужой месяц — блеклые,
   выходные — приглушённые. Точка под числом: серая — в этот день есть события Google Календаря / задачи со временем,
   золотая — срок другой задачи.
4. **Время = расписание выбранного дня**: лента 8:00–22:00 шагом 30 мин (22 px), на ней события дня из Google Календаря
   (нейтральные плашки). Клик по свободному месту — задача встаёт блоком clay с подписью «15:00–16:00 · <название>».
   Пересечение с событием — блок красный и подсказка «Пересекается с «…». Свободно с HH:MM» (ближайший свободный слот той же длины).
   Ниже точные минуты :00/:15/:30/:45 и длительность 30 мин / 1 ч / 2 ч / 3 ч.
5. **«Весь день»** — переключатель: лента прячется, срок без времени.
6. **Низ**: напоминание (Без / За час / Накануне в 10:00 — это правила `tasks[id].remind` из 0.2, уходят в Telegram),
   «Без срока» (снять срок), «Готово».
- Под полем в окне задачи — подсказка, куда уйдёт: без времени → срок в Google Tasks; со временем → ещё и событие в календаре
  (~~шаг 5 плана «задача со временем ↔ событие»~~ — отменён 20.10: напоминаний через бота достаточно). Длительность хранить в слое (`tasks[id].dur`), в Google Tasks времени нет.

## Шаблоны досок: редактор (утверждено 20.10)

Исходник — `design/screens/Templates.dc.html`. Экран «Шаблоны досок» (ссылка из левой колонки).

## Канбан и Конвейер: вид и взаимодействие (утверждено 20.10)

Исходники: `design/screens/Kanban.dc.html` (в свойствах доски `demo`: обычный / перетаскивание / меню),
`design/screens/Conveyor.dc.html`. Решение 0.2 остаётся: **на карточках доски нет галочки**, выполнено = последняя колонка.

### Общая модель (одинаково в Канбане, Конвейере и Списке)
- **Фокус** — одна выбранная карточка/строка (обводка clay). Мышь: наведение подсвечивает, клик выбирает и действует (ниже).
  Клавиатура: Tab заходит на доску, дальше стрелки.
- **Действия над выбранной** (те же клавиши, что в окне задачи): `Enter` — открыть окно задачи · `F2` или двойной клик
  по названию — переименовать на месте (Enter — сохранить, Esc — отмена) · `Alt+→ / Alt+←` — следующий / предыдущий этап ·
  `Alt+↑ / Alt+↓` — выше / ниже в колонке · `Alt+1/2/3/0` — приоритет · `D` — срок (открывает выбор даты у карточки) ·
  `M` — в другой список · `Ctrl+D` — дублировать · `Del` — удалить (с плашкой «Отменить» 6 с, без диалога) · `Esc` — снять выбор.
  Правый клик или `Shift+F10` / клавиша меню — то же меню с подписанными клавишами.
- **Любой перенос этапа** (стрелка, клик по этапу, перетаскивание, Alt+→) показывает плашку ««…» → UV · Отменить» (6 с).
- Перенос в последнюю колонку = задача выполнена в Google Tasks; из неё обратно — снова открыта.
- Все действия уже есть в `keys.js`/окне задачи — добавить группы «Доска · карточка» и «Конвейер» в окно «?».

### Канбан
- Колонка: сверху полоска цвета колонки (из шаблона), НАЗВАНИЕ, число, лимит «2 / 3» (ровно лимит — золото, больше —
  красный + строка «Больше лимита…»; перенос сверх лимита не запрещать), кнопки «＋» (новая задача **в начало** колонки)
  и «свернуть». Свёрнутая колонка — вертикальная полоса 46 px с числом и названием, клик разворачивает
  (`settings.fold[listId][colId]`). «Готово» по-прежнему свёрнуто до 2 карточек + «Ещё N →».
- Карточка: **полоска приоритета слева** (высокий — clay, средний — gold, низкий — ink-faint, без — нет), название до 2 строк,
  первая строка заметки, ряд чипов: срок (просрочено — красный, сегодня/завтра — clay), тип, **подзадачи** — чип
  «☑ 3 из 5» с квадратиками 6×6 по числу подзадач (до 8; отмеченные — бирюзовые; все отмечены — весь чип бирюзовый),
  🔔 напоминание. Отдельной полоски под карточкой нет (убрана по отзыву). Выполненные — зачёркнуто, без полоски приоритета и чипа подзадач.
- **Клик по карточке** — открыть окно задачи (как сейчас). Наведение/фокус показывают справа сверху три кнопки:
  `→` следующий этап · `📅` срок · `⋯` меню. Клик по кнопкам не открывает окно.
- **Перетаскивание**: карточка «поднимается» (тень, наклон −2°), исходное место — полупрозрачное, в целевой колонке —
  пунктирное место вставки высотой с карточку, колонка подсвечена рамкой clay. Можно и менять порядок внутри колонки.
- Клавиши: `↑ ↓` — по карточкам колонки, `← →` — в соседнюю колонку (на ту же высоту).
- Фильтры над доской: Все · !!! Важное · На этой неделе · Просрочено; переключатель вида Канбан · Конвейер · Список.

### Конвейер
- Строка: стрелка-раскрытие, превью, название + «проект · подпись», точка приоритета, дорожка этапов (подсказка с номером:
  «4 · Ретопология — сейчас»), «на этапе N дней», срок (просрочено — красный), кнопка «<след. этап> →»
  (заливается clay, когда все подзадачи этапа отмечены).
- **Клик по названию, превью или пустому месту строки — раскрыть/свернуть** (одновременно раскрыта одна строка;
  раскрытая прокручивается в вид). Клик по этапу дорожки — поставить на этап (не раскрывает), с «Отменить».
  Окно задачи — `Enter` или «Открыть полностью ↗».
- **Раскрытая строка** — три колонки + низ:
  1. **Этап «…»**: «2 из 4» + полоска, подзадачи этапа с отметками, поле «Подзадача этапа… Enter — добавить» (фокус остаётся
     в поле для следующей), подсказка «Этап закрыт — можно дальше», свёрнутое «▸ Подзадачи других этапов · N».
  2. **Детали**: срок (чип → выбор даты), приоритет `!!! !! ! —`, проект, напоминание, заметка (клик — редактировать).
  3. **Время по этапам**: горизонтальные полоски (текущий этап — clay), «всего N дн.», место под превью.
  - Низ: «← <пред. этап>», «Открыть полностью ↗», подсказки `Esc` свернуть · `Space` следующий ассет · `Enter` окно задачи.
- Клавиши: `↑ ↓` — по строкам, `→` раскрыть, `←` свернуть, `Space` — свернуть и раскрыть следующую, `1–7` — этап по номеру.

## Анимации интерфейса (утверждено 20.10)

Цель — мягко и быстро: движение подсказывает, откуда что пришло и куда ушло, но никогда не задерживает работу.
Ввод не блокируется анимацией; клик во время анимации сразу применяется.

### Токены (в `styles/tokens.css`)
- Длительности: `--dur-1: 120ms` (наведение, нажатие), `--dur-2: 180ms` (меню, чипы, плашки), `--dur-3: 260ms`
  (окно задачи, смена экрана, раскрытие строки), `--dur-4: 420ms` (праздник, вехи).
- Кривые: `--ease-out: cubic-bezier(.2,.8,.2,1)` (появление), `--ease-in: cubic-bezier(.4,0,1,1)` (уход),
  `--ease-pop: cubic-bezier(.3,1.4,.5,1)` (лёгкий «пружинный» отскок — только для мелочей: галочки, числа серий).
- Анимируем только `transform` и `opacity` (ещё `grid-template-rows` для раскрытия). Уход всегда быстрее появления (~0,7×).
- **Уменьшение движения**: при `prefers-reduced-motion: reduce` и при настройке «Анимации: минимум» — сдвиги и масштаб
  убираются, остаются только короткие (≤ 120 мс) затухания; «Выкл» — без анимаций. Настройка — `settings.motion`
  (`full | min | off`), внизу левой колонки рядом с «Что показывать». Енот подчиняется тому же правилу.
- Рамка фокуса с клавиатуры появляется мгновенно (без анимации).

### Каталог
1. **Смена экрана** (вкладки, `1–4`, `Q/E`): View Transitions API (WebView2 поддерживает) — старый экран гаснет за 120 мс,
   новый проявляется со сдвигом 12 px **со стороны направления** (вправо по вкладкам — справа, влево — слева), 220 мс.
   Подчёркивание активной вкладки переезжает к новой (общий элемент `view-transition-name: tab-ink`). Без поддержки — просто fade.
2. **Смена списка на доске** (`[ ]`, левая колонка): заголовок сдвигается на 6 px, колонки — crossfade 160 мс.
3. **Календарь** `← →`: сетка уезжает/приезжает на 24 px по направлению + fade, 200 мс. «Неделя ↔ Месяц» — crossfade и
   масштаб .98 → 1. Панель дня при выборе другого дня — содержимое crossfade 140 мс (панель не дёргается).
4. **Окно задачи**: выезжает справа на 24 px + fade 260 мс, фон-затемнение 180 мс; закрытие 180 мс.
5. **Поповеры и меню** (`⋯`, выбор даты, «Изменить сферу», «Создать»): scale .96 → 1 + fade от точки привязки
   (`transform-origin` у кнопки), 160 мс; закрытие 100 мс.
6. **Карточка канбана**: наведение — подъём на 1 px и тень, 120 мс; кнопки `→ 📅 ⋯` проявляются 120 мс.
   Перетаскивание: при захвате scale 1.02 и наклон −2° (140 мс), место вставки растёт по высоте 150 мс, колонка-цель
   подсвечивается рамкой; при отпускании остальные карточки съезжают на места через FLIP (`animate:flip`, 220 мс).
7. **Перенос на следующий этап** (`→`, `Alt+→`): в канбане карточка «перелетает» в соседнюю колонку (crossfade send/receive,
   260 мс); в Конвейере заливка этапа пробегает слева направо (220 мс), «сейчас» переезжает на следующий сегмент.
8. **Выполнение** (в «Готово», галочка в «Сегодня»): галочка рисуется (stroke-dashoffset, 200 мс), зачёркивание названия
   растёт слева направо (200 мс); через 600 мс строка плавно схлопывается по высоте (220 мс), чтобы успеть увидеть результат.
9. **Плашка «Готово · Отменить»** и другие (обновление, нет связи): въезд снизу/сверху на 12 px + fade 180 мс;
   внутри тонкая полоска-таймер на 6 с, на наведении таймер на паузе.
10. **Раскрытие строки Конвейера**: высота `grid-template-rows: 0fr → 1fr` 240 мс, три колонки проявляются по очереди
    с шагом 60 мс; стрелка поворачивается на 90°; сворачивание 180 мс. Раскрытая строка мягко прокручивается в вид.
11. **Подзадачи и прогресс**: галочка — «поп» (.8 → 1.1 → 1, 160 мс), квадратики/полоски прогресса заполняются 250 мс;
    когда отмечены все — кнопка «<этап> →» один раз мягко пульсирует кольцом clay (600 мс).
12. **Новая задача** (быстрое добавление, форма в колонке, «Входящие от Claude»): появляется со сдвигом 8 px сверху + fade,
    фон подсвечен clay 8 % и гаснет за 1,2 с.
13. **Числа** (счётчики колонок, «2 / 3», серии, «Октябрь · 14 из 19»): старое значение уходит вверх, новое приходит снизу, 180 мс.
14. **Привычки**: отметка — кольцо заполняется от центра (200 мс), число серии подпрыгивает (1 → 1.15 → 1, 240 мс);
    веха — уже есть `pop` + енот `cheer`, добавить 5–6 искр вокруг енота один раз (600 мс).
15. **Колонка свернуть/развернуть**: ширина 200 мс, текст гаснет раньше (80 мс).
16. **Синхронизация**: точка статуса мягко пульсирует, пока идёт обмен (opacity .4 ↔ 1, 1 с), по окончании — короткая
    вспышка бирюзовым.
17. **Первая загрузка**: скелетоны карточек с медленным перетеканием (1,2 с цикл); при «минимум» — статичные.
18. **Енот-«подглядыватель»** и большой енот — как есть; при «минимум/выкл» — замирают.

Реализация: общие пресеты в `lib/motion.js` (`fly`, `fade`, `pop` с учётом `settings.motion` и `matchMedia`),
Svelte `transition:` / `animate:flip` / `crossfade` для карточек, View Transitions API для смены экранов.

## Простые дела: вид «Стикеры» (утверждено 21.10)

Третий основной вид доски — для дел без этапов (личное, покупки, звонки). Макет — `design/screens/Stickers.dc.html`
(на холсте страница «Простые задачи · выбор», доска C), картинки — `design/screens/ref/stickers-*.png`.
Отвергнутые варианты (A «Плитки», B «Чек-лист») лежат на той же странице холста, их не делать.

### Место в системе
- Переключатель вида в шапке доски: **Канбан · Конвейер · Стикеры** (три основных). Вид «Список» остаётся в редакторе
  шаблонов; у списка с видом «Список» он показывается в переключателе четвёртым, у остальных — нет.
- Вид списка — `lists[id].view = 'stickers'`. Встроенный шаблон «Личное» получает вид по умолчанию `stickers`
  (у существующих списков со своим `lists[id].view` ничего не меняется). В редакторе шаблонов вид «Стикеры» — в выборе вида.
- Этапов нет: дело либо открыто, либо сделано (статус Google Tasks `completed`). Если у задачи в слое промежуточный
  `status` (список раньше был канбаном) — на стикере маленькая метка с названием колонки, больше ничего.
- **Кружок-отметка на стикере есть** — правило 0.2 «без галочки» относится к канбану, где «сделано» = последняя колонка.

### Темы
- Темы — свои у каждого списка: `lists[id].topics = [{ id, name, color }]` (цвет — из палитры сфер). Тема дела —
  `tasks[id].topic`. Новый список с видом «Стикеры» получает набор по умолчанию: Документы (clay), Покупки (gold),
  Звонки (type-work), Здоровье (type-study), Дом (type-personal). Дела без темы — колонка «Разное» (ink-faint),
  показывается, только если такие есть.
- Правка тем — пункт «Темы…» в меню `⋯` шапки доски: переименовать, цвет, порядок, удалить (дела уходят в «Разное»), добавить.
- Пустые темы в раскладке «По темам» не показываются (21.10, по просьбе пользователя): вместо них последней колонкой
  «Пустые темы» — кнопки «＋ Документы» и т. п., клик открывает новый стикер в этой теме. Если пусто во всех темах — видны все.
- `#тема` в тексте нового стикера (начало слова, без регистра: `#покуп` → Покупки) ставит тему и вырезается из названия.

### Переключатель «По темам | По срокам»
- В шапке слева от переключателя вида — одна кнопка-переключатель из двух половин, активная залита clay. Клик в любом
  месте кнопки или клавиша `G` меняет раскладку. Запоминается для списка: `lists[id].group = 'topic' | 'when'` (по умолчанию `topic`).
- **По темам**: колонки по темам в порядке `topics`, равной ширины (до 5 в ряд, дальше прокрутка вбок). Шапка колонки —
  квадратик цвета, НАЗВАНИЕ капсом, счётчик открытых. Справа в шапке доски — «Закреплённые сверху / Срочные сверху» (порядок внутри колонки).
- **По срокам**: три колонки одинаковой ширины, внутри — стикеры в две колонки:
  - «Сегодня» — срок сегодня **и просроченные**; подпись «ср, 21 октября · и просроченное»; подложка колонки clay 7 %.
  - «На неделе» — срок с завтра по воскресенье этой недели.
  - «Когда-нибудь» — без срока или позже воскресенья.
  Шапка колонки — название шрифтом `--font-display`, счётчик, подпись справа. Цвет стикера остаётся цветом темы,
  а над названием мелко капсом подписана тема. Кнопки «Закреплённые/Срочные сверху» в этом режиме скрыты.
- Порядок внутри колонки (оба режима): закреплённые → просроченные → с ближайшим сроком → свой порядок `tasks[id].ord`.

### Стикер
- Фон — цвет темы 24 % поверх `--raised` (светлая тема: 18 % поверх `#FFFDF6`), углы 4/4/14/4 px (загнутый правый нижний),
  тень. Наклон −1,5°…+1,5°, **постоянный для задачи** (из хэша id), при наведении выпрямляется, поднимается на 3 px и
  чуть увеличивается (`--ease-pop`). Сверху «скотч» — полупрозрачная полоска; у закреплённого вместо скотча кнопка-булавка clay.
- Внутри: (в режиме «по срокам» — тема), название `--font-display` 16 px до 3 строк, первая строка заметки, низ — срок

### Авто-определение списка и темы — `lib/route.js` (чистая логика + `tests/route.test.js`)
**Решение пользователя (21.10): это обычный алгоритм очков, без ИИ и без сети** — работает мгновенно при вводе, офлайн, бесплатно.
Claude выбирает список только в чатах («запиши в Спутник…» → «Входящие»), как сейчас; кнопки «спросить Claude» в окне нет.
`route(text, { lists, layer, tasks, current }) → [{ listId, score, why, topic?, project? }]` по убыванию. Источники очков:
1. **Явно**: `@список` в тексте (как в боте; начало слова, без регистра) — сразу выбор, `why: 'указано @…'`.
2. **Выученные слова**: `settings.route[слово] = { list, topic?, n }` — пишется, когда пользователь **вручную** сменил список
   или тему в окне и создал задачу: для 1–2 значимых слов названия (без предлогов, длина ≥ 4, основа — первые 5 букв).
   Вес растёт с `n`. Это главный способ «научиться».
3. **Словарь по видам/шаблонам** (встроенный, в коде): asset3d — lowpoly, highpoly, ретоп, скульпт, uv, развёртк, текстур,
   запек, рендер, модел, ассет, пропс, блокаут; work/client — клиент, смет, макет, правк, ревью, созвон, бриф, счёт, заказ;
   study — урок, курс, лекци, глав, конспект; personal — купить, забрать, оплатить, позвонить, записаться, продлить, убрать,
   почистить, починить, подарок.
4. **Темы стикеров**: имена тем списка и словарь тем (Покупки — купить/заказать/забрать/посылк; Звонки — позвонить/набрать/
   написать; Здоровье — врач/стоматолог/анализ/зал; Документы — продлить/полис/паспорт/налог/оплатить; Дом — убрать/
   почистить/починить/постирать). Даёт и список (со стикерами), и `topic`.
5. **Похожесть на задачи списка**: пересечение основ слов с названиями открытых и недавних (30 дней) задач списка.
6. **Проект** в конвейере: слово совпадает с именем проекта (основа) → `project`.
7. **Контекст**: список, открытый на доске сейчас (+ небольшой бонус); без совпадений — он же, `why: 'текущая доска'`.
Порог: если у лучшего мало очков — берём текущую доску, бейдж «текущая доска». Решение пересчитывается при вводе
(с задержкой 150 мс), **но после ручного выбора** списка или темы в этом окне — больше не перескакивает.

### «Состояние» (поповер от кнопки, 360 px)

**Где живут общие задачи (решить в первом шаге разработки, вместе с пользователем).** Google Tasks не умеет общие
списки между аккаунтами, а слой лежит в скрытой папке Drive каждого. Пользователь склоняется к варианту **общий файл на

  **Чужой** — только кружок. **Ничей** — пунктирный «+»; при наведении он раскрывается в чип «[мой кружок] Взять себе».
- Клик по кружку — тот же выбор исполнителя, что в окне задачи; клавиша **T** — взять выделенный стикер себе.
- Штамп «СДЕЛАНО» несёт кружок того, кто сделал. Если стикер закрыл другой участник — тост
  «Оля закрыла «…» · Вернуть» (при следующей синхронизации).
- Переключатель раскладки в общей сфере — «По темам | По срокам | **По людям**». «По людям»: колонка = человек (кружок и
  имя в шапке, «Я» первым, «Ничьи» последней, не принявших нет), кружки на стикерах не показываются, цвет — по теме.
  Перетащить стикер в колонку человека — отдать ему, в «Ничьи» — снять исполнителя.
- Фильтр «Все / Мои / Ничьи» — как у канбана (на стикерах «Без исполнителя» короче — «Ничьи»).

### 8. Конвейер в общей сфере (`ShareConveyor`)
- **Исполнитель есть у ассета и у каждого этапа.** Ассет «ведёт» один человек (кружок 30 px справа, перед кнопкой «дальше»).
  У этапа может быть свой исполнитель: маленький кружок 16 px в правом верхнем углу ячейки этапа (у текущего не рисуется —
  он и есть кружок ассета). Этап без исполнителя — без кружка.
- **Передача:** при «Этап →» исполнитель ассета становится исполнителем следующего этапа (если у этапа никого — не меняется).
  Следующий этап другого человека обведён его цветом, а в кнопке «дальше» — его кружок («Текстуры → (А)»). У получателя
  строка с золотой меткой «(кружок) передано тебе · от Макса» до первого открытия.
- Раскрытая строка: слева «Кто на этапах» (этап, кружок + имя, ✓ дата / дней на этапе / ▾ — выбор), текущий подсвечен
  clay; справа «Как передаётся» — короткая история передач. Под ними: кнопка следующего этапа и подсказка, у кого он
  останется. Клавиши: **I** — исполнитель текущего этапа, **Shift+I** — кто ведёт ассет.
- Переключатель «По проектам | По людям» (группы по тому, кто ведёт ассет) + фильтр «Все / Мои / Ничьи».
- В слое: `tasks[id].who` (кто ведёт), `tasks[id].stageWho = { <колонка>: <участник> }`.
