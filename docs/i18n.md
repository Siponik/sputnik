# Язык интерфейса (русский / English)

Исходный текст — русский. Перевод — один файл `rust/i18n/en/LC_MESSAGES/sputnik.po` (gettext, без `msgctxt`), его читают и Slint, и Rust.

- **Разметка `.slint`**: `text: @tr("Сегодня");`, с подстановкой — `@tr("Задач: {}", n)`. Slint берёт перевод из того же .po при сборке (`build.rs`: `with_bundled_translations("../i18n")`, без контекста). Склейки `"Задач: " + n` заменять на `@tr` с `{}`.
- **Rust** (`app/src`, `core/src`): `t!("Текст")` → `&str`, `t!("Ошибка: {}", e)` → `String`. Только `{}` и `{0}`; переменные в скобках (`{e}`) переписать на `{}`. В `app` — `sputnik_core::t!`, в `core` — `crate::t!`.
- **Множественное число**: `habits::plural(n, ["задача", "задачи", "задач"])` уже переводится. В .po ключ — три формы через «|», перевод — две: `msgid "задача|задачи|задач"` → `msgstr "task|tasks"`.
- **Даты**: только через `core::i18n` — `month`, `month_gen`, `month_short`, `wd` (0 — пн), `wd_sun` (0 — вс), `wd3`, `wd_full`, `day_month` («12 ноября» / «Nov 12»), `month_year`, `day_range`. Своих массивов месяцев и дней не заводить.
- **Не переводить**: слова, которые программа разбирает (`when.rs`, `route.rs` — «завтра», «@список», «#тип»), id, ключи слоя, названия, которые уходят в Google (имя списка «Привычки», календари «Спутник · …»), текст, сверяемый с данными пользователя.

Язык — Настройки → Вид → «Язык»: `settings.lang.v` = `ru` | `en` | `sys` (по умолчанию — как в системе: русский/белорусский/украинский/казахский — по-русски, остальное — English). `settings::apply_lang` ставит язык для Rust (`i18n::set_lang`) и для Slint (`select_bundled_translation`). Для снимков — `SPUTNIK_LANG=en`.

Проверки: `cargo test -p sputnik-core --test i18n` — у каждой строки в `@tr(...)` и `t!(...)` есть непустой перевод с тем же числом `{}`. Сколько ещё не обёрнуто: `cargo test -p sputnik-core --test i18n left -- --ignored --nocapture`.
