# Спутник на Rust + Slint — устройство

Папка `rust/`, два крейта:

- `core` — чистая логика (разбор «когда», маршрут «Куда», привычки, шаблоны, напоминания, общие сферы). Без сети и окна, золотые тесты сверяют её с прежней логикой трекера.
- `app` — программа `sputnik`. Слои сверху вниз, вызовы только вниз:
  1. `data/` — Google (вход, запросы), файлы. Пишет только в `%APPDATA%\com.siponik.sputnik\rust\`; старые `token.json`, `client_secret.json`, `layer.json` только читает.
  2. `state/` — `App`: данные, действия, очередь правок `Outbox` (повторы 5 с…5 мин, временные id → настоящие), синхронизация, общие сферы (`shared.rs`, задания по одному в фоне). Сеть и диск — в фоновых потоках (`state::bg`), результат возвращается в окно через `invoke_from_event_loop`, поэтому окно не ждёт сеть.
  3. `view/` — собирает модели Slint из `App` и `Ui` (состояние экрана). После любого действия `view::act` → `render()` перерисовывает только открытый раздел.
  4. `ui/*.slint` — разметка «Системы G». Всё общение — глобал `S` в `store.slint`: свойства-модели и колбэки. Разметка ничего не считает.

Проверка без Google: `SPUTNIK_DEMO=1` (примерные данные, сеть и запись выключены). Для снимков: `SPUTNIK_TAB`, `SPUTNIK_BOARD`, `SPUTNIK_CAL`, `SPUTNIK_OPEN=create:K:текст | task:список:id | search:запрос | note:путь`.

«Знания» (`app/src/notes.rs`): разбор — `pulldown-cmark` (MIT, ссылки `[[…]]`, теги, заголовок), слежение за папкой — `notify` (CC0), граф — `core/src/graph.rs`, раскладка по алгоритму d3-force (ISC) с Барнсом–Хатом.

Тесты: `cd rust; cargo test` (часовой пояс — Москва). CI на PR — `.github/workflows/rust-check.yml` (тесты и `cargo check` под Windows); сам `sputnik.exe` собирается после слияния (`rust-release.yml`, ниже).

Обновление из приложения (`state/update.rs`): пуш в beta или main с изменениями в `rust/` → `.github/workflows/rust-release.yml` собирает `sputnik.exe` версии 0.1.<номер сборки>, подписывает ключом трекера и кладёт `latest.json` в служебный релиз `rust-latest` (релизы «не последние» — обновлению трекера не мешают). Приложение проверяет через 30 с после запуска и раз в 6 ч, чип «✦ Версия …» в шапке, «Обновить сейчас» — проверка подписи, замена файла (старый — `sputnik.old.exe`, удаляется при следующем запуске) и перезапуск.
