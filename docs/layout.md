# Правила раскладки и масштаба

Чтобы ничего не вылезало за рамку при любом размере окна и масштабе Windows (100–150 %). Правила для всех экранов Rust-версии (`rust/app/ui/*.slint`). Что проверяется автоматически, лежит в `rust/core/tests/layout_rules.rs`.

## 1. Содержимое не растёт за рамку — оно прокручивается внутри

- У окна, карточки, ноды и панели размер задан извне: от окна или фиксированный, как «Создать» 840×620. Содержимое этот размер не раздувает.
- Список, заметка, подзадачи и любой текст, который может стать длиннее, прокручиваются внутри своего места: `ScrollView`, `Flickable` или `ScrollInput`.
- Многострочный ввод — только `ScrollInput` (`kit.slint`). Курсор в нём всегда виден. Голый `TextInput { single-line: false }` разрешён, только если вся колонка уже прокручивается. Такое место помечается комментарием `// раскладка: в прокрутке`. *(Проверяется тестом.)*

## 2. Одна строка обрезается, абзац переносится

- Название, значение в строке «Свойств», чип, шапка ноды — `overflow: elide` с заданной шириной. Ширина задаётся как `parent.width - отступы`, а не числом.
- Подсказки, описания и тексты пустых состояний — `wrap: word-wrap`, а высота места берётся от `preferred-height` текста или задаётся с запасом.
- Ряд чипов, который может не влезть, переносится на вторую строку отдельным рядом, а не уезжает вправо.

## 3. Высота считается от содержимого или с запасом

- Если блок рисуется по координатам (`y: …`), его высоту считают с учётом пустого состояния. Пример: «Сборка дня» без задач резервирует место под пустое состояние.
- Фиксированные высоты (`height: 124px`) ставятся только там, где внутри есть прокрутка или обрезка.

## 4. Только иконки, никаких эмодзи и редких символов

- Значки берутся из `design/system-g/icons/` через `Icon { name: … }`. Стрелка выпадающего списка — `Chev`.
- Эмодзи и символы, которых нет в шрифтах Windows (◷ ↻ ✦ ▾ ▸ 📅…), показываются там квадратами. Поэтому их нет нигде, кроме комментариев. *(Проверяется тестом.)*

## 5. Выпадашки и попапы прижаты к окну

- Выпадашка открывается под своим полем и выравнивается по его левому краю. Если не влезает по ширине, её прижимают к правому краю. Высота не больше ~260 px, дальше прокрутка.
- Окно, внутри которого открываются выпадашки, не ставит `clip: true`, иначе их обрежет. Скругления шапки делаются через `border-top-*-radius`.
- Большие окна поверх (окно «Срок», шаблоны) ставятся через `max(8px, …)` от краёв и размеряются от `self.width` / `self.height`, а не от чисел, записанных в другом файле.

## 6. Ширина окна

- Минимальный размер окна — около 1090×580 логических точек: это ноутбук при масштабе 150 %. Всё должно влезать в него, а разделы — прокручиваться.
- Шапка ужимается ступенями (`app.slint`). Новые элементы шапки должны уметь прятать подпись.

## Как проверить руками

`SPUTNIK_DEMO=1 cargo run -p sputnik`, затем уменьшить окно до минимума и открыть экран. Ничего не должно обрезаться посередине, а длинное должно прокручиваться.
