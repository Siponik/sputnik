# Гнёзда и провода («соединялки») — Система G

Как рисовать связи между нодами, чтобы везде было одинаково. Код образца — `design/system-g/gen/kit.py` (`sock`, `wire`, `vwire`, `svg`).

## Цвета

| Имя | Hex | Где |
|---|---|---|
| GREY | `#A3A5AE` | «Входящие», нейтральная колонка |
| OR (акцент) | `#F0A04B` | «В работе», задача |
| VIO | `#B48CF0` | «На проверке», день рождения |
| GREEN | `#7FD18C` | «Готово» |
| BLUE | `#6FA2F2` | событие |
| GOLD | `#E8C65A` | привычка |
| RED | `#F0785F` | просрочено, ошибка |
| GROUND | `#191A1E` | обводка гнезда (цвет подложки) |

Правило: **цвет гнезда и провода = цвет ноды-источника** (колонки, вида записи, сферы). Колонка может иметь свой цвет из настроек списка — тогда берётся он.

## Гнездо (sock)

- Квадрат 10×10, скругление 3, `box-sizing: border-box`.
- Полное: заливка цветом источника, обводка 1.5 цвета GROUND (отрезает от фона).
- Пустое (ring): заливка GROUND, обводка 1.5 цветом источника — для входа, куда ещё ничего не пришло, или необязательной связи.
- Выход — справа у источника (`right: -6px`), вход — слева у цели (`left: -6px`); по вертикали — по центру шапки ноды.

## Провод (wire)

- Безье: `M x1 y1 C x1+k y1, x2-k y2, x2 y2`, толщина 1.5, без заливки.
- Цвет — цвет источника. Пунктир `4 4` — связь необязательная или ещё не случилась.
- `k`: 8–12 для коротких промежутков (между колонками), 40–60 для длинных (окно → нода предпросмотра).
- Вертикальный вариант `vwire` — когда ноды друг под другом.
- Провод рисуется под нодами, концы точно в центрах гнёзд.

## Где уже есть

- Канбан: колонка → следующая колонка (гнёзда в шапках, провод цвета левой колонки).
- Окна «Создать»: окно → нода предпросмотра, провод цвета вида записи.
- Конвейер и экраны «Сегодня»/«Сборка дня».

## Как добавить в новом месте

1. Определить источник и цель, взять цвет источника.
2. Поставить `sock('r', y, цвет)` у источника и `sock('l', y, цвет)` у цели.
3. Провести `wire(...)` между центрами гнёзд внутри общего `svg()`.
4. В Rust: один компонент-гнездо и одна функция провода с этими же числами — не копировать стиль по месту.
