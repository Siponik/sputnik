# Канбан и Конвейер: как довести до макета (инструкция для Claude Code, 20.10.2026)

Читать целиком перед работой. Спецификация — `docs/design-v2.md`, разделы «Канбан и Конвейер: вид и взаимодействие» и «Анимации интерфейса». Этот файл — не новая спецификация, а **порядок работы**.

## Почему не получалось

Ты работал вслепую: трекер без Google не запускается, а макеты `*.dc.html` — шаблоны холста, их нельзя просто открыть в браузере. Отсюда серия «fix: … match Kanban.dc.html» наугад. Теперь видно и то, и другое:

| Что | Как получить |
|---|---|
| Как должно быть | `design/screens/ref/*.png` — готовые картинки макетов. Перерисовать или снять другое состояние: `node tools/design/render-dc.mjs design/screens/Kanban.dc.html out.png "demo=меню"` (из корня репозитория; можно `--click ".nm"`) |
| Как есть сейчас | `cd tracker; npm run demo` — трекер в браузере на выдуманных данных (`src/demo/`: Tauri и Google подменены, в сеть ничего не уходит), http://localhost:1421. Потом в другом окне `cd tracker; npm run shot` → `tracker/shots/*.png` |

Для `npm run shot` и `render-dc.mjs` нужен Playwright — один раз: `cd tracker; npm i -D playwright; npx playwright install chromium`.

Демо-данные (`src/demo/data.js`) — те же задачи, что на макетах: доска «Иконки для клиента» = `Kanban.dc.html`, «3D-проекты» = `Conveyor.dc.html`. Картинки можно класть рядом один к одному.

## Правила

1. **Не переписывать с нуля.** Почти всё уже есть (коммиты dbbfa50, 5961033, 2db37a7, b087165): `lib/Board.svelte`, `lib/TaskCard.svelte`, `lib/CardMenu.svelte`, `lib/Conveyor.svelte`, `lib/motion.js`, `styles/board.css`, `styles/conveyor.css`, `styles/motion.css`, плашка с «Отменить» — в `App.svelte` (`say(msg, undo)`). Задача — найти расхождения и исправить их.
2. Решения 0.2 главнее макета: на карточке нет галочки; выполнено = последняя колонка; «Готово» уходит в архив через 3 дня.
3. Клавиши — по `e.code` (русская раскладка). Новые клавиши — сразу в `lib/keys.js` (окно «?»).
4. Макеты (`design/screens/*.dc.html`) не менять, `design/screens/ref/` не перерисовывать без нужды. `tracker/shots/` не коммитить.
5. Анимируются только `transform` и `opacity` (раскрытие строки — `grid-template-rows`). Длительности и кривые — только токены `--dur-*`, `--ease-*`.
6. Маленькие коммиты, по одной группе из списка ниже. После каждой группы: `npm run build` без ошибок → `npm run shot` → посмотреть пару картинок (инструментом Read) → коммит.
7. Если одно и то же место не сходится после двух попыток — остановись, приложи обе картинки и спроси пользователя. Не гадай третий раз.

## Цикл работы

```
1. npm run demo            (оставить запущенным)
2. npm run shot
3. Открыть пару: shots/kanban.png и design/screens/ref/kanban-обычный.png
4. Выписать расхождения в таблицу ниже (✅ / ❌ + что не так)
5. Исправить одну группу → build → shot → сравнить → коммит
6. Повторить для меню, наведения, Конвейера, светлой темы
```

## Проверочный список

Отмечай прямо в этом файле (✅ / ❌ и пара слов), коммить вместе с исправлениями — так видно, где остановился.

### A. Шапка доски — `kanban.png` ↔ `ref/kanban-обычный.png`
- [ ] Над названием мелко «Сфера · шаблон «…»», название списка крупным шрифтом `--font-display`.
- [ ] Справа в одну строку: фильтры «Все · !!! Важное · На этой неделе · Просрочено» (выбранный — с обводкой), разделитель, переключатель «Канбан | Конвейер | Список» в общей рамке.
- [ ] Фильтры реально фильтруют (Важное = приоритет 1, Неделя = срок ≤ 7 дней, Просрочено = срок < сегодня и не выполнено).

### B. Колонка
- [ ] Шапка: НАЗВАНИЕ капсом мелким, счётчик серым, справа «＋» и «‹» (свернуть).
- [ ] Под шапкой линия 2 px цветом колонки (Входящие серая, В работе синяя, На ревью золотая, Готово бирюзовая).
- [ ] Лимит «2 / 3» рядом со счётчиком; ровно на лимите — золотой, больше — красный + строка «Больше лимита…».
- [ ] «＋» открывает форму **сверху** колонки; «+ Добавить задачу» внизу колонки — форма внизу. Enter — добавить и оставить форму открытой, Esc — закрыть.
- [ ] «‹» сворачивает колонку в вертикальную полосу 46 px (название вертикально, счётчик), клик по полосе — развернуть; запоминается в `settings.fold`.
- [ ] «Готово»: видно 2 карточки, ниже «Ещё N →».
- [ ] Колонки фиксированной ширины ~290 px, не растягиваются на весь экран; лишнее место справа пустое.

### C. Карточка
- [ ] Слева полоска 3 px: приоритет 1 clay, 2 золото, 3 серая, без приоритета — нет полоски.
- [ ] Название жирное, до 2 строк; ниже первая строка заметки серым.
- [ ] Чипы: срок (сегодня/завтра — clay, просрочено — красный «просрочено · вчера»), тип с точкой цвета типа, подзадачи «☑ 3 из 5» + квадратики (все готовы — весь чип бирюзовый), 🔔 напоминание.
- [ ] Выполненная (в «Готово»): название зачёркнуто, серое, чип «✓ 14 окт.».
- [ ] Наведение (`kanban-hover.png`): справа сверху три кнопки → 📅 ⋯, клик по ним **не** открывает окно задачи.
- [ ] Выбранная карточка (клавишами или кликом) — рамка clay, как вторая карточка «В работе» на макете.

### D. Меню задачи — `kanban-menu.png` ↔ `ref/kanban-меню.png`

- [ ] После отпускания карточки соседние плавно съезжают (FLIP), порядок сохраняется.
- [ ] Перенос в другую колонку → плашка «‘…’ → На ревью · Отменить» с полоской-таймером 6 с; «Отменить» возвращает.

### F. Клавиши канбана (проверять в демо, после проверки — отметить)

- [ ] Alt+←/→ — этап (с плашкой «Отменить»), Alt+↑/↓ — порядок, Alt+1/2/3/0 — приоритет, D — срок, M — в другой список, Ctrl+D — копия, Del — удаление с «Отменить» (без диалога), Esc — снять выбор.
- [ ] Всё работает в русской раскладке.
- [ ] Внизу доски строка подсказок как на макете; в «?» есть группы «Доска · карточка» и «Конвейер».
